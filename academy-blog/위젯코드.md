# 네이버 블로그 위젯 코드 (복사·붙여넣기용)

네이버 플레이스 ID: **13588084** (베이직클래스)

## 사용 방법

1. `images/btn1~5_170x170.png` 5개를 **비공개 글 하나에 올립니다.** 각 이미지를 우클릭한 뒤 "이미지 주소 복사"를 눌러 아래 `이미지_주소_①~⑤` 자리에 붙여넣습니다.
2. 수업 안내 등 고정 글과 카테고리를 만든 뒤, 그 주소를 `글_주소`와 `카테고리_주소` 자리에 붙여넣습니다.
3. **관리 → 꾸미기 설정 → 레이아웃·위젯 설정 → 위젯 직접등록**에서 아래 코드를 하나씩 등록하고, 위젯을 ①부터 ⑤까지 순서대로 가로로 배치합니다.

> ④·⑤의 플레이스 주소는 이미 채워 두었습니다. 등록한 뒤에는 PC와 휴대폰에서 각각 한 번씩 눌러 보고 제대로 열리는지 확인하십시오.

---

### ① 수업 안내 → 고정 글
```html
<a href="글_주소_수업안내" target="_blank"><img src="이미지_주소_①" width="170" height="170" alt="수업 안내"></a>
```

### ② 시간표·반 안내 → 고정 글
```html
<a href="글_주소_시간표반안내" target="_blank"><img src="이미지_주소_②" width="170" height="170" alt="시간표·반 안내"></a>
```

### ③ 학교별 내신 → 카테고리
```html
<a href="카테고리_주소_학교별내신" target="_blank"><img src="이미지_주소_③" width="170" height="170" alt="학교별 내신 정보"></a>
```

### ④ 오시는 길 → 네이버 지도 (길찾기)
```html
<a href="https://map.naver.com/p/entry/place/13588084" target="_blank"><img src="이미지_주소_④" width="170" height="170" alt="오시는 길"></a>
```

### ⑤ 전화 상담 → 네이버 플레이스 (전화 버튼 → 스마트콜)
```html
<a href="https://m.place.naver.com/place/13588084/home" target="_blank"><img src="이미지_주소_⑤" width="170" height="170" alt="전화 상담 0507-1480-3536"></a>
```

- ⑤는 플레이스 **홈** 화면으로 연결됩니다. 휴대폰에서는 화면 위쪽의 "전화" 버튼을 누르면 스마트콜(0507)로 연결되고, 안내 멘트가 나와 상담 전화임을 구분할 수 있습니다(개편안 4.1).
- PC에서는 플레이스 화면에 0507 번호가 표시되고, 버튼 이미지에도 같은 번호가 적혀 있습니다.

## 글 하단 상담 문구에 넣을 링크

글을 쓸 때 **"장소" 첨부로 '베이직클래스'를 검색해 지도를 넣으십시오.** 이렇게 하면 글이 플레이스와 연결되어 지역 검색에 도움이 됩니다. 텍스트 링크를 넣으려면 아래 주소를 씁니다.

```
https://m.place.naver.com/place/13588084/home
```

## 공유용 짧은 주소

플레이스 화면에서 "공유 → URL 복사"를 누르면 `naver.me/xxxx` 형태의 짧은 주소가 나옵니다. 문자·전단·QR코드에는 이 짧은 주소를 쓰는 것이 깔끔합니다.
